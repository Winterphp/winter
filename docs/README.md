# Documentation Winter

Référence du framework [Winter](https://github.com/winterphp/winter) — un framework PHP 8 inspiré de **Spring Boot** : stéréotypes par attributs, injection par constructeur, un seul dossier `src/` organisé librement.

| [migration-depuis-laravel.md](migration-depuis-laravel.md) | Correspondances Laravel → Winter |
| [audit-securite.md](audit-securite.md) | Constats de l'audit, risques acceptés, vérifications à rejouer |
